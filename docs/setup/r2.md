# Menyiapkan Cloudflare R2 (tempat semua gambar)

Gambar situs (±3.200 file, ±507 MB) disimpan di **Cloudflare R2**, bukan di Sanity, supaya Sanity tetap
ringan dan biaya penyimpanan murah (R2 tidak menarik biaya bandwidth/egress). Sanity hanya menyimpan
alamat gambarnya. Kodenya sudah siap; yang perlu dilakukan pemilik akun hanya langkah 1–4 di bawah
(±15 menit), lalu developer menjalankan langkah 5–7.

Yang sudah ada di proyek:

- Studio (`/studio/`): field gambar punya tombol **Upload** dan **Media library** (pilih gambar yang sudah
  ada di bucket, bisa dicari berdasarkan nama file) — `src/sanity/components/R2ImageInput.tsx`.
- `POST /api/media/upload` dan `GET /api/media/list`: hanya bisa dipakai editor yang login di Studio
  (dicek ke Sanity; role Viewer ditolak). Kunci R2 hanya ada di server, tidak pernah di browser.
- `scripts/media/copy-uploads-to-r2.mjs`: menyalin semua gambar dari WordPress ke bucket dengan path
  yang sama (`wp-content/uploads/2026/10/nama.png`).
- Saklar `NEXT_PUBLIC_MEDIA_BASE_URL`: kalau diisi, semua gambar ditampilkan dari bucket; alamat lama
  `/wp-content/uploads/…` di domain ini di-redirect ke bucket.

## 1. Buat bucket

1. Login ke https://dash.cloudflare.com → menu kiri **R2 Object Storage**. (Pertama kali: aktifkan R2;
   Cloudflare minta kartu untuk paket berbayar, tapi 10 GB pertama gratis — situs ini butuh ±0,5 GB.)
2. **Create bucket** → nama: `peptidesbali-media` → Location: **Automatic** (atau Asia-Pacific) →
   **Create bucket**.

## 2. Alamat publik bucket

Gambar harus bisa dibuka pengunjung. Pilih salah satu:

- **Disarankan — domain sendiri** (cepat, di-cache Cloudflare): bucket → **Settings** → **Custom Domains**
  → **Connect Domain** → `media.peptidesbali.online` (domainnya harus ada di Cloudflare). Alamat publik:
  `https://media.peptidesbali.online`
- **Sementara — alamat r2.dev**: bucket → **Settings** → **Public Development URL** → **Enable**. Alamat
  publik: `https://pub-xxxxxxxx.r2.dev` (Cloudflare menyebut ini untuk pengembangan, ada batas akses).

## 3. CORS bucket (supaya Studio bisa menampilkan gambar)

Bucket → **Settings** → **CORS Policy** → **Add CORS policy** / Edit, tempel:

```json
[
  {
    "AllowedOrigins": ["http://localhost:3000", "http://localhost:3005", "https://peptidesbali.online"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["*"],
    "MaxAgeSeconds": 86400
  }
]
```

(Tambahkan alamat staging Vercel kalau sudah ada.)

## 4. API token (rahasia)

1. Halaman **R2 Object Storage** → **Manage API tokens** (kanan atas) → **Create API token**.
2. Nama: `peptidesbali-site`. Permissions: **Object Read & Write**. Specify bucket: **hanya**
   `peptidesbali-media`. TTL: Forever. **Create API Token**.
3. Cloudflare menampilkan **Access Key ID** dan **Secret Access Key** sekali saja. Juga catat
   **Account ID** (ada di halaman R2, kanan).
4. Isi sendiri di `.env.local` (folder proyek, sebelah `package.json`):

   ```
   R2_ACCOUNT_ID=...
   R2_ACCESS_KEY_ID=...
   R2_SECRET_ACCESS_KEY=...
   R2_BUCKET=peptidesbali-media
   R2_PUBLIC_URL=https://media.peptidesbali.online
   ```

**Jangan kirim key/secret lewat chat**, e-mail atau screenshot. Kalau bocor: hapus token di halaman yang
sama lalu buat baru. Account ID, nama bucket dan alamat publik bukan rahasia.

Di Vercel nanti: isi variabel yang sama di Project → Settings → Environment Variables.

## 5. Salin gambar dari WordPress ke bucket (developer)

```bash
node scripts/media/copy-uploads-to-r2.mjs --dry-run
```

```bash
node scripts/media/copy-uploads-to-r2.mjs
```

```bash
node scripts/media/copy-uploads-to-r2.mjs --check
```

- `--dry-run` hanya menghitung (sekarang: 3.216 file).
- Tanpa flag: menyalin 3 file sekaligus (sopan untuk server WordPress, hanya GET file publik). File yang
  sudah ada di bucket dilewati, jadi aman dijalankan ulang kalau terputus.
- `--check`: memastikan setiap file bisa dibuka lewat `R2_PUBLIC_URL`.
- File yang gagal (mis. 1 gambar yang memang sudah 404 di live) dicatat di `.data/media/`.

## 6. Pindahkan tampilan gambar ke bucket

Setelah `--check` bersih, tambahkan di `.env.local` (dan Vercel):

```
NEXT_PUBLIC_MEDIA_BASE_URL=https://media.peptidesbali.online
```

lalu build ulang (`npm run build`). Mulai saat itu:

- halaman, produk, blog, popup: alamat `https://peptidesbali.online/wp-content/uploads/…` ditulis ulang ke
  bucket (`src/lib/media/url.ts`);
- alamat lama `/wp-content/uploads/…` di domain ini (gambar latar di CSS Elementor, link dari situs lain,
  Google Images) di-redirect 301 ke bucket (`next.config.ts`).

## 7. Cek

1. Buka beberapa halaman: gambar dimuat dari `media.peptidesbali.online` (DevTools → Network).
2. Studio → buka halaman mana saja → widget **Picture** → **Upload**: file masuk ke
   `wp-content/uploads/<tahun>/<bulan>/` di bucket dan langsung tampil.
3. **Media library**: daftar gambar muncul, bisa dicari (mis. `bpc`), centang **Show all sizes** untuk
   melihat versi ukuran kecil dari WordPress.

## Catatan

- Upload menerima JPEG, PNG, WebP, GIF, AVIF sampai 15 MB. SVG ditolak (bisa berisi script).
- Studio login dengan token di browser (`auth.loginMethod: "token"` di `sanity.config.ts`) supaya route
  upload bisa memastikan siapa editornya ke Sanity. Kalau tombol Upload bilang "log in again": logout
  dari Studio lalu login lagi.
- Menghapus gambar dari bucket sengaja tidak ada di Studio (gambar bisa dipakai di banyak halaman).
  Hapus lewat dashboard Cloudflare kalau benar-benar perlu.

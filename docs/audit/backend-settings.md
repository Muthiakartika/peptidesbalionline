# Backend settings audit (A5)

Read on **6 Nov 2026** in the live wp-admin. The owner's side signed in themselves; I only read pages and the
REST API from that session. Nothing was saved or changed. Not copied here: secret or API keys, payment
account details, coupon codes, customer or affiliate data. Where a setting holds such a value, this file only
says that it is set.

Versions: WordPress 7.1.4, WooCommerce 11.2.1 (HPOS order tables on), AffiliateWP 2.37.4, Elementor 4.3.5 +
PRO Elements 4.3.2, Woodmart Core 1.1.5.

## 5. Stock (answers Q-04)

Stock management is on, but **no product tracks a quantity** (all 182 products have it off): stock is a status
set by hand. Across the 501 products + variations: 445 in stock, 44 on backorder, 12 out of stock (15 products
show "on backorder" as a whole). Low-stock e-mail at 2, out-of-stock at 0, unpaid orders hold stock 60 minutes.

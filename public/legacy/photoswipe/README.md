# PhotoSwipe icons

`default-skin.svg` and `default-skin.png` are the button icons of PhotoSwipe 4.1.3's default skin,
unchanged (byte-for-byte the files the live site serves from its theme). They are used by
`src/styles/photoswipe.css` for the product gallery's "Click to enlarge" viewer.
